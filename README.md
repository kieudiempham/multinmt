# VietNMT

Transformer-based Neural Machine Translation for English-Vietnamese Translation.

## Goal

Develop and evaluate neural machine translation systems for English-Vietnamese translation using Transformer architectures.

## Planned Features

- Data preprocessing
- Transformer training
- BLEU evaluation
- Model inference API
- Hugging Face deployment

## Tech Stack

- Python
- PyTorch
- Hugging Face Transformers
- SacreBLEU
